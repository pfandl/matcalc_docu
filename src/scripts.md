MatCalc scripts
===============

MatCalc scripts are text files, containing a list of commands to be executed in the order from top to bottom. They are particularly useful to speed up routines or repetitive operations. Once a script file has been created, it can easily be modified to serve a new purpose, for example by changing the elements or phases in the system. In addition, script files are much smaller in size than MatCalc workspace files, especially those resulting from precipitation and microstructure calculations.

Find a collection of MatCalc scripts for different aspects of material processing below.
