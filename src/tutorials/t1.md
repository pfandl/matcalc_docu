T1: Introduction to the MatCalc graphical user interface (GUI)
--------------------------------------------------------------

*This tutorial was tested on   
MatCalc version 6.10 rel 1.002   
license: free

The graphical user interface
----------------------------

|  |  |
| --- | --- |

| Toolbar | Icons giving quick access to frequently used functions (see  [below](/matcalc_docu/tutorials/t1#toolbars "tutorials:t1")) |

### Menu bar

As with any typical GUI application, this gives access to a number of sub-menus. The **File** and **Help** menus are documented in this tutorial, and the contents of the other menus will be described in more detail in subsequent tutorials.

|  |  |
| --- | --- |
| **File** | opening, saving and closing files (see **'File operations'** below) |
| **Edit** | text-editing commands such as undo, redo, cut, copy, paste |
| **Global** | commands for setting up the system (see [Tutorial 2](/matcalc_docu/tutorials/t2 "tutorials:t2") and subsequent tutorials) |
| **Calc** | commands for the most frequent types of calculation (see [Tutorial 2](/matcalc_docu/tutorials/t2 "tutorials:t2") and subsequent tutorials) |
| **Cells, Monte Carlo** | commands for starting calculation within additional MatCalc modules |
| **Script** | to run scripts (more on this in  [Tutorial 13](/matcalc_docu/tutorials/t13 "tutorials:t13")) |
| **View** | to configure the GUI and create new windows for the display of results (see [Tutorial 4](/matcalc_docu/tutorials/t4 "tutorials:t4") and [Tutorial 5](/matcalc_docu/tutorials/t5 "tutorials:t5")) |
| **Help** | see [Getting help](/matcalc_docu/tutorials/t1#getting_help "tutorials:t1") below |

On platforms running under **MacOS** an additional menu **'mcg'** is also present. Comprehensive information about the menu items can be found in the [reference book](/matcalc_docu/reference/menu "reference:menu").

### Configuring the layout

#### Rearranging the position of toolbar elements and windows

In addition to the arrangement options available in Quick access bar, toolbar icon groups and the **'Options'**, **'Variables'**, **'Nodes'** and **'Console'** windows can be detached from their locations and rearranged as desired by dragging and dropping.

#### Bar 'Right-click' menu

Right-clicking on the **'menu bar'**, **'toolbar'** or **'quick access bar'** brings up a menu allowing the user to show or hide menu icon groups and windows as described  [above](/matcalc_docu/tutorials/t1#managing_toolbar_elements "tutorials:t1") ('Managing toolbar elements').

#### Menu 'View' > 'Show'

Enables the following windows to be displayed or hidden: 'console' (F4), 'options' (F3), 'variables' (F2), 'node manager' (Shift + F5). It corresponds with the functionalities of the respective  [Quick access bar](/matcalc_docu/tutorials/t1#quick_access_bar "tutorials:t1") icons.

[![Menu: show windows](/matcalc_docu/tutorials/t1/img/t1_menu_show_windows_6101002.png "Menu: show windows")](/matcalc_docu/tutorials/t1/img/t1_menu_show_windows_6101002.png "tutorials:t1:img:t1_menu_show_windows_6101002.png")

#### Menu 'View' > 'Select window font'

Here the user can select an alternative font/font size for the display of numerical output. This does not affect the appearance of the 'console', 'nodes', 'options' and 'variables' windows.

[![Menu: window font settings](/matcalc_docu/tutorials/t1/img/t1_menu_window_font_6101002.png "Menu: window font settings")](/matcalc_docu/tutorials/t1/img/t1_menu_window_font_6101002.png "tutorials:t1:img:t1_menu_window_font_6101002.png")

#### Menu 'View' > 'Select application style'

The overall appearance of MatCalc can be modified here. The different options offer a greater or lesser degree of free space around text items, stronger or more subtle contrast etc. - experiment with the items of the drop-down list until you find an option that suits you.

[![Menu: application style settings](/matcalc_docu/tutorials/t1/img/t1_menu_application_style_6101002.png "Menu: application style settings")](/matcalc_docu/tutorials/t1/img/t1_menu_application_style_6101002.png "tutorials:t1:img:t1_menu_application_style_6101002.png")

MatCalc workspace
-----------------

Having learned about the GUI elements, it is time to meet the **'MatCalc workspace'** concept. Technically speaking, MatCalc workspace is an object which can be handled by MatCalc GUI. It contains all the necessary information on the user calculations, comprising inputs (elements, phases, compositions, thermodynamic and mobility data) and outputs (results of calculations, graphs, etc.). Saving the workspace preserves all the information for future use. Needless to say, the very first step to perform any simulations in MatCalc GUI is to provide the workspace – either by creating a new one or loading one created before.

### The 'File' menu

Basic workspace operations can be accessed in menu 'File'. Clicking on **'File'** in the menu bar opens the following menu:

[![ MatCalc file menu](/matcalc_docu/tutorials/t1/img/t1_menu_file_6101002.png " MatCalc file menu")](/matcalc_docu/tutorials/t1/img/t1_menu_file_6101002.png "tutorials:t1:img:t1_menu_file_6101002.png")

### Creating a new workspace

To create a new workspace, do *one* of the following:

* Click on the respective icon on the toolbar

[![ MatCalc icon new](/matcalc_docu/tutorials/t1/img/t1_icon_new_6101002.png " MatCalc icon new")](/matcalc_docu/tutorials/t1/img/t1_icon_new_6101002.png "tutorials:t1:img:t1_icon_new_6101002.png")

* Click on **'New'** from the **'File'** menu

[![ Menu: new](/matcalc_docu/tutorials/t1/img/t1_menu_file_new_6101002.png " Menu: new")](/matcalc_docu/tutorials/t1/img/t1_menu_file_new_6101002.png "tutorials:t1:img:t1_menu_file_new_6101002.png")

* Press **Ctrl + N** on the keyboard
* Click on the **'New workspace'** button

[![ New workspace button](/matcalc_docu/tutorials/t1/img/t1_new_workspace_button_6101002.png " New workspace button")](/matcalc_docu/tutorials/t1/img/t1_new_workspace_button_6101002.png "tutorials:t1:img:t1_new_workspace_button_6101002.png")

The following dialogue box will appear (except when clicked on **'New Workspace'** button):

[![ MatCalc new file](/matcalc_docu/tutorials/t1/img/t1_new_file_6101002.png " MatCalc new file")](/matcalc_docu/tutorials/t1/img/t1_new_file_6101002.png "tutorials:t1:img:t1_new_file_6101002.png")

Select **'MatCalc workspace'** from the drop-down list and click on **“OK”** button.

[![ MatCalc new file](/matcalc_docu/tutorials/t1/img/t1_new_file_workspace_6101002.png " MatCalc new file")](/matcalc_docu/tutorials/t1/img/t1_new_file_workspace_6101002.png "tutorials:t1:img:t1_new_file_workspace_6101002.png")

This runs a script file called **autonew.mcs**, which makes two additional windows appear: **Phase details** and **Phase summary**. When the new workspace is first created, the **Phase summary** and **Phase details** windows show messages indicating that no phases have yet been selected. The workspace is now ready for thermodynamic or precipitation calculations to be set up and performed.

[![ MatCalc Screenshot](/matcalc_docu/tutorials/t1/img/t1_workspace_screenshot_6101002.png " MatCalc Screenshot")](/matcalc_docu/tutorials/t1/img/t1_workspace_screenshot_6101002.png "tutorials:t1:img:t1_workspace_screenshot_6101002.png")

Do not close the individual windows on the screen before saving, or their contents will not be saved!

Working directory
-----------------

Another important concept for the input/output operations of MatCalc (including saving or loading MatCalc workspaces) is the one of **'working directory'**. This is the directory on the user system drive opened by default when MatCalc is saving any output files or looking for any input files. Clicking on **'Working directory…'** in the **'File'** menu allows the user to designate an existing directory as the working directory or to create a new directory for this purpose. MatCalc remembers your chosen working directory for next time.

[![ MatCalc working directory](/matcalc_docu/tutorials/t1/img/t1_menu_working_directory_6101002.png " MatCalc working directory")](/matcalc_docu/tutorials/t1/img/t1_menu_working_directory_6101002.png "tutorials:t1:img:t1_menu_working_directory_6101002.png")  
[![ MatCalc working directory](/matcalc_docu/tutorials/t1/img/t1_working_directory_6101002.png " MatCalc working directory")](/matcalc_docu/tutorials/t1/img/t1_working_directory_6101002.png "tutorials:t1:img:t1_working_directory_6101002.png")

The paths of the current working directory and of recently used working directories are listed to the right of **Recent working dirs…**, allowing any of these directories to be selected easily.

[![ MatCalc recent working directories menu](/matcalc_docu/tutorials/t1/img/t1_menu_recent_workdirs_6101002.png " MatCalc recent working directories menu")](/matcalc_docu/tutorials/t1/img/t1_menu_recent_workdirs_6101002.png "tutorials:t1:img:t1_menu_recent_workdirs_6101002.png")
