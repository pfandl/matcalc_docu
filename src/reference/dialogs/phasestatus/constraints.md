Constraints
-----------

This tab allow you to set constraints to a certain phase. With setting a constraint, a para-/ortho-equilibrium situation can be simulated. Refer to [Para-/Ortho-equilibrium](/matcalc_docu/examples/equilib/e1#ortho-equilibrium_vs_para-equilibrium "examples:equilib:e1") section in example E1.

[![ Constraints](/matcalc_docu/reference/dialogs/img/phasestatus/phase_status-f8-constraints.png " Constraints")](/matcalc_docu/reference/dialogs/img/phasestatus/phase_status-f8-constraints.png "reference:dialogs:img:phasestatus:phase_status-f8-constraints.png")

1. **Element status:** Shows all read elements and the amount of fixed phase, in case a constraint is set.
2. **Set para-equil.:** Set a constraint for the selected phase.
3. **Set orto-equil.:** Undo the constraint for the selected phase.
4. **[Edit ...:](/matcalc_docu/reference/dialogs/phasestatus/constraints/edit "reference:dialogs:phasestatus:constraints:edit")** Edit constraints within the dialog box.
