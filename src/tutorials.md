MatCalc tutorial
================

The tutorial documents of this sections are aimed at *demonstrating the basic handling* of the MatCalc software. The sections start with typical operations using the GUI, performing simple calculations of thermodynamic equilibrium and post-processing of the results in graphical form.

If you are a newbie to MatCalc, try out the tutorial sections one by one and you will become acquainted to the basic features and functions of the software. You will also learn how to set up kinetic simulations and how to solve simple heat treatment problems.
