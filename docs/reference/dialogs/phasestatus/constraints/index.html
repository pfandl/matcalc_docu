Constraints [MatCalc Documentation]

Constraints

This tab allow you to set constraints to a certain phase. With setting a constraint, a para-/ortho-equilibrium situation can be simulated. Refer to Para-/Ortho-equilibrium section in example E1.

  1. Element status: Shows all read elements and the amount of fixed phase, in case a constraint is set.
  2. Set para-equil.: Set a constraint for the selected phase.
  3. Set orto-equil.: Undo the constraint for the selected phase.
  4. Edit ...: Edit constraints within the dialog box.
