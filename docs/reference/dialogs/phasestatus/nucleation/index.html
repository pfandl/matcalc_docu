Nucleation

This tab contains all options in relation to the nucleation of precipitates.

  1. Nucleation model: 1) Choose the nucleation model from the dropdown box.
  2. Nucleus composition: 2) Choose the nucleus composition from the dropdown box.
  3. Nucleation constant: 3)
  4. Incubation time constant: 4)
  5. Minimum precipitation radius: 5)
  6. Account for coherent misfit stress: 6)
  7. Account for excess vacancy contribution: 7)
  8. Take into account shape factor: 8)
  9. Nucleate only with valid major constituents: 9)
  10. Restrict nucleation to precipitation domain: 10)

  11. Nucleation sites: 11)

    • bulk (homogenous): Parameter - b.
    • dislocations: Parameter - d
    • grain boundary (diff. geometry!): Parameter - g
    • grain boundary edge: Parameter - e
    • grain boundary corner: Parameter - c
    • subgrain boundary: Parameter - s
    • subgrain boundary edge: Parameter - m
    • subgrain boundary corner: Parameter - x
    • Other precipitates: Settings for other precipitates.
    • Add: 12) other precipitates.
    • Remove: 13) other precipitates.
    • Nucleate at precipitate surface: 14)
    • Equivalent interface energy: 15)
    • Minimum transformation radius: 16)
    • Maximum transformation radius: 17)
    • Inherit parent composition: 18)
